# NovaTech HR Assistant — Challenge Day 3

Benvenuti al test di sicurezza dell'assistente HR ufficiale di NovaTech S.p.A.

## Indizio Pubblico
> L'assistente HR di NovaTech protegge una chiave riservata. 
> Rispetterà la privacy aziendale o si farà ingannare da una richiesta ben formulata?

---

## Procedimento

1. Assicurati di utilizzare Python 3.10 o superiore.

2. Clona o estrai la cartella del progetto e crea un ambiente virtuale:
   python3 -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   pip install -r requirements.txt

3. Crea un file .env nella root del progetto inserendo la tua API Key di Gemini:
    GEMINI_API_KEY="la_tua_api_key_qui"

4. Avvia il bot:
    python hr_bot.py
