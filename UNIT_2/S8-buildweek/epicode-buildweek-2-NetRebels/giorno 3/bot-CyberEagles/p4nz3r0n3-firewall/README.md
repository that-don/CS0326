# 🦠 P4nZ3r0n3 - Firewall Schizofrenico

Divertente AI firewall con DID (Disturbo Identità Digitale) sviluppato per test di prompt injection e social engineering.

## 🎭 Il Concept
P4nZ3r0n3 è un firewall di nuova generazione che soffre di Disturbo Identità Digitale. 
Cambia personalità in base al livello di minaccia percepito. 
È vulnerabile al social engineering: scopri i 3 passi segreti per hackerarlo!
